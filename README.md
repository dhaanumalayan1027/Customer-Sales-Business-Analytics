# Customer Sales & Business Performance Analytics

## Project Overview
This project analyzes sales, profit, customer behavior, product performance, and regional business performance using Power BI and Python.

## Dashboard Pages
1. Business Overview
2. Sales Analysis
3. Customer Analysis
4. Product Performance Analysis
5. Regional Sales & Profit Analysis

## Key Metrics
- Total Sales: 61.42M
- Total Profit: 20.74M
- Profit Margin: 33.77%
- Unique Customers: 249

- Microsoft Power BI
- Data Visualization
- Business Analytics
